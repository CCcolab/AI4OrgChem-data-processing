# 公开学习分发说明

当前固定版本为[v0.1.0](RELEASE_v0.1.0_zh-CN.md)。GitHub Release中的版本归档仅包含公开学习文件；项目内的内部统一交付包和原始验收材料继续单独保存，不作为发布资产上传。

当前目录为7个专业分类、32项独立Python Skill，完整指令、代码包和SHA-256可公开查看下载。每项runtime目录是自己的配套程序，不要求启动另一个项目的Runtime或Docker；实际科学库/用户后端仍按各页配置。

移出的共用助手不在当前分发中。五项新便携真实后端继续标PARTIAL_BACKEND_PENDING，历史证据不自动变成新计算通过。

公开仓库只包含学习源码、教材/方法引用、自编教学案例、下载与维护检查工具。最终内部统一交付包另含移除助手、独立运行和下载复验的完整记录，仅保存本项目，不上传该包或内部日志。

公开不新增或改写现有许可/第三方归属，详见RIGHTS_REVIEW.md。历史中已入库的教学发布摘要和来源核对保留，不用旧验收替代当前科学边界。

CI可在私有准备阶段和公开后运行同一学习资料边界检查；维护者推送器仍要求实际仓库名和PLATFORM_ENTRY可见性匹配、干净工作区、通过检查及非强制推送。公开源并非任意后端代码的安全沙箱，也不提供统一执行服务。
