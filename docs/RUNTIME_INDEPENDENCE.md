# 独立Python环境与后端说明

目录由7个专业分类、32项Skill组成。用户直接选择Skill，先读README与完整SKILL.md，再使用该页的Python入口；没有共用助手路由或统一Runtime启动步骤。

常规入口不以AI4OrgChem-Runtime、Docker、安装登记或固定磁盘路径为准入条件。各自的Python科学库与用户已有后端仍需按README配置；独立环境用于避免不兼容依赖混装，不能把“无需Docker”理解为无需安装科学依赖或所有后端都能原生在Windows运行。

五项正式功能限输入准备、结果复核和JSON导入；[新计算调用单列开发预览](DEVELOPMENT_PREVIEW.md)。默认准备/已有数组或账本复核与新量子求解是不同工作；开发预览中的可选PySCF由已有受支持环境提供，程序不自动创建Docker/WSL或安装软件。机器学习案例是有范围的本地教学任务，不证明化学预测泛化；模型训练/推理需用户选择执行，不因打开或下载页面自动发生。

部分已有数组保留原Runtime的提交、文件哈希等历史溯源，这是数据来源关联，不是运行依赖。所需教学数据和代码已随包提供，正常使用不读取原Runtime安装目录。旧输出和历史PASS不能代替新计算的真实回执、收敛与数值检查。

本页描述用户操作和适用范围，内部检查日志不进入分发。移出的旧共用运行助手保留在历史版本，当前目录不提供其下载或路由入口。
