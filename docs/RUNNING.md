# 阅读、运行和保存

1. 在课程首页按顺序打开lessons/*.ipynb；GitHub预览显示已保存的文字、公式和静态图表，不执行Python。
2. 点击“在Colab打开”，登录自己的Google账号；建议先另存到自己的Drive。使用CPU，不需要GPU、Docker或AI密钥。
3. 选择“代码执行程序→全部运行”，首次从PyPI安装私有venv依赖，需要联网及Python>=3.12。课程计算在私有新内核执行，不覆盖Colab预装环境。安装失败应停止，不能忽略后续错误。
4. 核对默认参数输出，再手工修改声明的参数并从头运行。文本/数值输入后按Tab提交，以运行回执中的parameter为准。
5. 查看下方整课输出、图表、错误拒绝例与结果回执。F01漏项FAIL是预期结果；F02是历史保存数据复核，不是新RHF。
6. “文件→在云端硬盘中保存一份副本”保存课程，再用“文件→下载→下载.ipynb”保存到电脑。最后单元输出中的下载链接提供结果ZIP；也可在保存Notebook中保留内嵌附件。运行时文件不能当作永久保存。

Drive另存副本、Notebook下载与单独ZIP下载分别检查。已验证五份原生Notebook及其中的结果ZIP完整性；独立ZIP按钮下载仍未验。自动化没有取得原生下载事件不等于文件已经或未被用户下载。

Colab页首导航指向公开仓库；内置原课历史段落中的相对链接可能被Colab解析到其它域，请使用页首导航或课程首页。通过Notebook页首当前状态识别旧输出中的历史验收文字。切勿上传私有实验数据或凭据到公开Notebook。
