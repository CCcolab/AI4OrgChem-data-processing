# Python使用方式

从[目录](../START_HERE_zh-CN.md)进入Skill README，先看科学范围和案例数据来源，再下载完整Python包。在Windows有写入权限的短路径解压，每个Skill创建单独Python3.12环境，按runtime/requirements.txt安装。机器学习模块会在本机训练小模型，不调用大语言模型服务，也不下载未知预训练权重。

顶层README解释知识、参数与案例；完整SKILL.md提供可下载指令；runtime中的.py实际读取SKILL.md、校验输入、执行工具及保存结果。无语言模型模式只读取/保存Skill身份，不声称模型理解了指令。输入、参数、环境、结果和回执对应同一轮，写Skill外全新目录；复制结果文件夹或results.zip保存。

用户CSV只在明确支持的入口使用，不猜列名、单位或标签。量子模块当前区分准备、旧数组复核和真实后端运行；已有结果及软件PASS不自动继承为新计算通过。准备和已有结果复核不要求启动Docker；真实计算使用用户明确选择的已有后端，不自动更换环境。

各学习页把知识原理、公式前提与案例输出对应，再分别列教材/专著的基础章节、方法原论文和软件实现依据。只核对到书目/目录的引用会明确标注，不把目录当作逐式正文核验；软件API文档也不替代化学或统计理论。各Skill由用户直接选择；文件摘要等工程检查依据相应标准，不以经典化学教材证明引擎已运行。

保存结果时同时保留输入、参数、Skill快照和回执。带缩放表达的拟合优先使用回执指定的稳定求值形式；原坐标系数能显示，并不保证直接代入时数值稳定。统计计算失败与样本不足的“未定义”必须分开读取；分类概率需要连同类别顺序保存，未校准概率不等于经验证的化学风险。
